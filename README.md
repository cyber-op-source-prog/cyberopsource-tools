# Cyber Op Source Tools

Privacy-first, no-tracking tools and utilities built by **Cyber Op Source**.

This repository contains small, focused tools designed to solve real problems without collecting user data, embedding trackers, or adding unnecessary complexity.

## Principles

- **Privacy-first** — no analytics, no tracking, no hidden data collection  
- **Transparent** — readable code, clear purpose  
- **Practical** — tools meant to be used, not demoed  
- **Minimal** — no bloat, no noise  

## What You’ll Find Here

- Lightweight web-based tools (HTML/CSS/JS)
- Small automation scripts and utilities
- Reference implementations and helpers
- Experiments that may grow into standalone tools

## Tool Index

All tools are privacy-first and run locally in your browser (no uploads, no tracking).

- **Base64 to Image** — Decode Base64 strings into images (client-side)
- **JWT Decoder** — Inspect JWT header/payload locally
- **SHA-256 Hash Generator** — Generate hashes in-browser
- **JSON Formatter** — Prettify + validate JSON
- **JSON Minifier** — Minify JSON locally
- **IP Subnet Calculator** — IPv4 CIDR + network/broadcast + hosts
- **PII Scrubber** — Redact sensitive data locally (in development)
- **SQL Architect Pro** — Schema builder + dialect SQL generation (planned)

## Usage

Most tools in this repository are designed to run:
- Locally in a browser, or
- Locally via simple scripts

See individual tool folders for usage instructions.
